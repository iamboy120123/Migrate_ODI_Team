---
description: บอกผู้อนุมัติว่าต้องอนุมัติอะไร และอนุมัติอย่างไร (PR comment หรือ commit เอง) — AI ติ๊ก ✅ แทนไม่ได้
argument-hint: "[Q14 | G2.M1 | W1 ...]"
---
1. รวบรวมสิ่งที่รออนุมัติจาก `status/OPEN_DECISIONS.md` (Q ที่ยังไม่มี [x]), `status/GATES.md` (manual ที่ยัง [ ]) และ Waiver log — หรือเฉพาะ `$ARGUMENTS`
2. ต่อข้อ: บอกเรื่อง · ตัวเลือก + [แนะนำ] + เหตุผล · ผลของแต่ละทาง (ภาษาง่าย) · ไฟล์หลักฐาน
3. วิธีอนุมัติ (ผู้อนุมัติเลือกทางใดทางหนึ่ง):
   - **ทาง PR:** เจ้าของงาน push แล้วเปิด draft PR · ผู้อนุมัติ comment บรรทัดละข้อ เช่น `/approve Q14 B` · `/approve G2.M1` · `/approve W1`
     → GitHub Action `approve-command` ใส่ `✅ SA <วันที่> @<ผู้อนุมัติ> <ลิงก์ comment>` ให้เอง แล้วเจ้าของงาน `git pull`
   - **ทางแชท:** ผู้อนุมัติอยู่ในแชทนี้และตอบเอง → AI บันทึกบรรทัดพร้อม `✅ SA <วันที่> @<ชื่อ GitHub ของผู้อนุมัติ>` แล้ว **ผู้อนุมัติ commit จากบัญชีของตัวเอง**
4. CI `verify-approvals` ตรวจทุกบรรทัด ✅ ที่เพิ่มใน PR ว่ามาจากผู้อนุมัติจริง — AI / เจ้าของงานติ๊กแทน = CI ไม่ผ่าน
5. ห้ามแก้ไฟล์ในคำสั่งนี้ (ยกเว้นกรณีทางแชทที่ผู้อนุมัติตอบเองในแชท)
