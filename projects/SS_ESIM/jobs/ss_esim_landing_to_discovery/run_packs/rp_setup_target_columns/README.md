# Run Pack: ขอโครงสร้างคอลัมน์ของตารางปลายทาง (I3)

ไฟล์ `T1_target_columns.sql` เป็น SELECT เดียว อ่านอย่างเดียว ไม่แก้ข้อมูล — kit ใส่ชื่อตารางที่ job เขียนลง (จาก export ของ Blendata) ให้แล้ว 8 ตาราง

## วิธีทำ
1. เปิด `T1_target_columns.sql` ในเครื่องมือ SQL ที่ต่อ Oracle **ปลายทาง** (ตัวที่ใช้กับ dev ของงานนี้ เช่น DBeaver) — ต้องมีสิทธิ์ SELECT บน `all_tab_columns`
2. รันทั้งไฟล์ (SELECT เดียว: Ctrl+Enter ใน DBeaver)
3. Export ผลลัพธ์เป็น **CSV ที่มีหัวคอลัมน์** (หัวต้องมี `TABLE_NAME`, `COLUMN_NAME`)
4. วางไฟล์ CSV ที่ `input\oracle_ddl\` (ชื่ออะไรก็ได้ เช่น `target_columns.csv`)

## ผลที่ควรได้ / ถ้าไม่ตรง
- ตารางที่มีอยู่แล้วใน Oracle จะมีแถวของทุกคอลัมน์ · **ตารางที่ยังไม่ได้สร้างจะไม่มีแถวเลย** — ให้บอกใน `/intake` ว่าตารางไหนยังไม่มี (kit ไม่สร้างตารางให้ ต้องให้ DBA สร้าง)
- ไม่มีสิทธิ์ หรือไม่สะดวกรัน: ข้ามได้ kit จะเดาชื่อคอลัมน์จากชื่อ field ใน SQL ต้นทาง และระบุทุกครั้งว่า "เดา ยังไม่ยืนยัน"
- ห้ามรันบน Prod โดยไม่ผ่านผู้ดูแลฐานข้อมูล (query นี้ SELECT ล้วน แต่ให้ใช้ environment ของงานนี้เท่านั้น)
