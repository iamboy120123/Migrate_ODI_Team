# กฎ: ถามแล้วต้องบอกว่า "แนะนำข้อไหน" ทุกครั้งที่มีตัวเลือก

ใช้กับ **ทุกคำถามที่ agent ถามผู้ใช้ ทุก command ทุก phase** (`/intake`, `/decide`, `/review-sql`, `/diagnose`, `/gate`, `/cutover` ฯลฯ) ทั้งคำถามที่ agent คิดขึ้นเอง และ Q ที่ยกมาจาก `status/OPEN_DECISIONS.md` — ถ้า Q ในไฟล์ยังไม่มี **[แนะนำ]** ให้ agent เติมให้ก่อนยกมาถาม

## เมื่อมีตัวเลือกให้เลือก (2 ข้อขึ้นไป รวมถึง ใช่/ไม่ใช่ ที่ผลต่างกัน)

ในข้อความเดียวกับคำถามต้องมีครบ 3 อย่าง:

1. ใส่ **[แนะนำ]** ที่ตัวเลือก **เพียงข้อเดียว**
2. **เหตุผล** จากข้อเท็จจริงของงานนี้ — อ้างไฟล์ / ค่า / ผลที่อ่านได้ (เช่น "`config/partitions_check.csv` ระบุ partition ว่าง") ไม่ใช่ความชอบหรือความเคยชิน
3. **เมื่อไหร่ควรเลือกข้ออื่นแทน** — บอกเงื่อนไขสั้นๆ

รูปแบบตัวอย่าง:

> 1) ... **[แนะนำ]**
> 2) ...
> 3) ...
> เหตุผลที่แนะนำข้อ 1: ... (ที่มา: `<ไฟล์/ค่า>`) · เลือกข้อ 2 แทนเมื่อ ... · เลือกข้อ 3 แทนเมื่อ ...

## เมื่อข้อมูลไม่พอจะแนะนำ

**ห้ามปล่อยว่าง และห้ามเดา** — เขียนให้ชัดว่า "ยังไม่แนะนำข้อไหน" พร้อมระบุ **ขาดข้อมูลอะไร** และ **ได้ข้อมูลนั้นมาจากไหน** แล้วบอกว่าถ้าได้ข้อมูลแล้วจะแนะนำทางไหน (เช่น "ถ้า Q3 = dynamic แนะนำข้อ 1 · ถ้า static แนะนำข้อ 3")

## ข้อยกเว้นและข้อห้าม

- คำถามแบบ **พิมพ์ค่า** (ชื่อ, path, ตัวเลข) ไม่มีตัวเลือก → ไม่ต้องมี [แนะนำ] แต่ต้องมีตัวอย่างคำตอบ · ถ้ามีค่าที่อ่านจากไฟล์ได้ ให้เสนอค่านั้นเป็นค่าตั้งต้นแล้วขอแค่ยืนยัน
- คำถามใช่/ไม่ใช่ที่ชัดอยู่แล้ว ถามสั้นได้ แต่ต้องบอกว่า "ใช่" หมายถึงอะไร และแนะนำให้ตอบอะไรเมื่อผลต่างกัน
- **I12 (ทาสก์ที่ implement ตรงๆ ไม่ได้):** ห้ามแนะนำให้ "ตัด" ทาสก์ (กฎเดิมของ `knowledge/reference/intake-questions.md`) — แนะนำได้เฉพาะ **วิธี** ที่ปลอดภัยต่อข้อมูล เช่น placeholder · และต้องบอกผลกระทบทางธุรกิจที่ agent มองไม่เห็นว่าเป็นของ SA
- ห้ามใส่ [แนะนำ] มากกว่า 1 ข้อ · ห้ามแนะนำเพราะ "ทำง่ายกว่าสำหรับ agent" โดยไม่บอกว่ามีผลกับ semantics / ความเสี่ยงอย่างไร
- แนะนำแล้ว **ไม่ใช่การตัดสินใจ** — ยังต้องรอ SA ตอบ และใส่ `✅ SA <วันที่>` เฉพาะเมื่อ SA ตอบในแชต (CLAUDE.md §6.1 / §9)

## ตรวจก่อนส่งทุกครั้ง (self-check)

มีตัวเลือก → มี [แนะนำ] 1 ข้อ + เหตุผล + เงื่อนไขข้ออื่น? หรือ บอกชัดว่าไม่แนะนำเพราะขาดอะไร? ถ้าไม่ครบ อย่าส่ง
